## Cara Upload ke GitHub Pages
1. Ekstrak `SIM-PUNCHLIST-Kelompok4-v2.zip`.
2. Ganti/timpa file `index.html` lama di repository GitHub Anda dengan `index.html` terbaru ini.
3. Buka tautan GitHub Pages Anda (`https://<username>.github.io/<nama-repo>/`) dan tekan `Ctrl + Shift + R` (atau *refresh* browser HP).
